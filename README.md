# Usercoop

[Usercoop](https://github.com/jezerostudiorepo/usercoop/blob/main/usercoop%20design%20document%20-%20CURRENT.md) is proposed as an offline, personal programmable Expert System, that knows about the user’s locally defined world and can operate the device as part of that world.

Its subjective contextual interface is an alternative to both windowing systems and terminals.
